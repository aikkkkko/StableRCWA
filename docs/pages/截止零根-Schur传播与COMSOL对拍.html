本征值正确性：数值根、独立子空间与传播

1. 三种退化需要分别判断

情形线性代数结构对 RCWA 的直接影响
半单重根代数重数 = 几何重数，有完整本征子空间子空间内可换基；界面和传播同步变换时物理场不变。
亏损重根 / Jordan 块独立本征向量不足，需广义本征向量或不变子空间只用标量指数会丢失 z·exp(−qz) 等项。
q = 0 的上下行合并exp(−qξ)、exp(+qξ) 同时趋于 1二阶方程仍有 1、ξ 两个解；沿用两列相同的波基会丢失线性解。
约化模式构造退化小矩阵的 λ 接近 0，重建完整电磁模式时发生相关圆锥入射可同时有 q² = λ + kᵧ² ≠ 0；需要完整算符的稳定基。

2. 小本征残差不能证明模式基可用

rⱼ = ‖Avⱼ − λⱼvⱼ‖₂ / (‖A‖F ‖vⱼ‖₂)，　κ₂(V) = σmax(V) / σmin(V)

残差检验每一对 (λⱼ,vⱼ) 是否满足本征方程；κ₂(V) 检验这些向量合起来是否能稳定表示任意场。重复返回同一个合法向量时，每列残差仍可为零，但 V 已经奇异。RCWA 后续的模式展开与界面匹配需要完整、可用的基，因此必须区分这两个问题。

例如 A = diag(0,0,1)，把前两列都选成 e₁，三对本征残差都是零，却丢失了 e₂。另一个例子 A = [[0,1],[0,ε]]：当 ε → 0，两列本征向量几乎平行，κ(V) 随 1/|ε| 增大；ε = 0 时只剩一个本征向量。增加小扰动可以分开数值根，却改变了所求问题。

3. 非厄米问题的判据

一般非厄米、非正规算符的本征向量本来就可以不正交。orthogonality_defect(V) 适用于考察正规问题的正交性，不能作为一般非厄米问题的失败条件。对于厄米重根，可在同一本征子空间内构造正交基；对不同本征值直接做 Gram–Schmidt 会破坏 Av = λv。对一般非正规或亏损问题，Schur 分解保留整个不变子空间及其耦合，是 StableRCWA 在退化层采用的方法。

H Z = Z T，　Z†Z = I，　T 为上三角矩阵

Schur 向量是稳定的子空间坐标；T 的非对角项记录模式间耦合。只取 diag(T) 并把 Z 当作普通本征向量，会再次丢掉这些耦合。这里沿用通用 QR 的变换累积接口，RCWA 直接消费 Z、T；通用 eig() 的本征向量回代算法保持原实现。

4. 当前 QR 回代在零重根附近的实际行为

通用 QR 先经 Householder 化为 Hessenberg 形，再用酉 QR 迭代得到上三角 T，最后回代 (T−λⱼI)xⱼ=0 并乘回 Z。回代公式 xᵢ = Σk>iTᵢₖxₖ/(λⱼ−λᵢ)，问题集中在谱间隔很小的分母。

现有实现对严格为零的分母使用 max(eps,机器精度)×max|Tᵢⱼ| 替代；若该量下溢则使用最小正规数。对非零但很小的分母，则使用 max(eps,机器精度)×max(|λᵢ|₁,|λⱼ|₁) 作下限，|·|₁ = |Re|+|Im|。

零根簇中若 |λ| 本身已是 O(u‖A‖)，后一阈值可以只有 O(u²‖A‖)，而 Schur 非对角扰动仍可为 O(u‖A‖)。因此商依然可能很大，归一化后的向量依然可能几乎相关。分母保护能控制部分数值溢出，却不能保证重根子空间的秩；对于真正亏损的矩阵，独立本征向量在数学上就不存在。退化层直接保留 Schur 表示，避开了该回代需求。

5. 病态检测与可疑结果复核分别检查什么

本征对残差回答“每列是否是近似解”；σmin 与 κ₂ 检查“这些列能否展开所有场”；Schur 残差 ‖HZ−ZT‖/‖H‖ 与酉性缺损检查“子空间表示是否正确”；界面线性系统残差、切向场连续性和 Maxwell 方程残差检查“解是否正确接入物理问题”。重复根之间应比较子空间或重建的场，逐列相位或排序的差异不构成物理误差。

当前生产路径采用约化谱的逐层触发判据、平方根残差和有限数检查；独立一阶场、界面连续性与 Maxwell 差分残差在回归测试中复核。全模式条件数和上述全部指标没有作为每次 RCWA 调用的固定开销加入。这样明确区分了自动运行的判据和测试时的交叉验证。

6. 为什么这种误差会传到衍射效率

若完整界面系统写为 Bc = b，数值扰动满足一阶关系 δc ≈ B⁻¹(δb − δB·c)。模式基相关会放大 B 的条件数，进而放大内部振幅和出射振幅误差。场 E = Fc 同时受到 δF 和 δc 影响；某个通道 η = f|J|²，在固定通量权重 f 下有：

δη = f [2 Re(J*δJ) + |δJ|²]，
|δη| ≤ f (2|J||δJ| + |δJ|²)

因此不存在一个只由“有重根”就能确定的误差百分比。误差大小取决于丢失的解、激发方向、层厚、界面条件数和观测位置。临界外部阶 f → 0 时，其自身法向功率趋小，复场仍可有限，并通过界面耦合改变其他传播级。后文同时给出复振幅、效率和复电场误差。

平面有限层精确零根：完整推导与实现

1. q = 0 不是把指数设成 1 就结束

每个可解耦模式满足 f″(ξ) = q²f(ξ)。非零 q 的解可由 exp(±qξ) 表示；零根处必须保留它们的合流极限：

limq→0 cosh(qξ) = 1，　limq→0 sinh(qξ)/q = ξ
f(ξ) = A + Bξ，　[f(h), f′(h)]ᵀ = [[1,h],[0,1]] [f(0), f′(0)]ᵀ，　h = k₀d

传播状态矩阵含非零的 h 项；将 q 换成一个小数或者让正反两列都变成常量，都会改变这一传播关系。

2. 辅助界面基与有限散射块

物理 q 保持为零，仅在有限层的界面基中令该列 basis_q = 1。TE 的配对基为 V = W·diag(basis_q)，TM 为 V = ⟦1/ε⟧W·diag(basis_q)。这些辅助振幅表示场及导数，并非两束可独立辨认的行波。

设上表面入射辅助振幅为 a，下表面入射辅助振幅为 b；上表面出射为 u，下表面出射为 v。零模式的场与归一化导数在上表面为 a+u、−a+u，在下表面为 v+b、−v+b。由导数恒定、场跨层增量为 h 倍导数：

−a + u = −v + b，
v + b − (a + u) = h(−a + u)
⇒ v = [2a + hb]/(2+h)，　u = [ha + 2b]/(2+h)
Tdd = Tuu = 2/(2+h)，　Rdu = Rud = h/(2+h)

这个非零“反射块”是辅助坐标下的传播关系。与两侧真实材料界面组合后，得到物理反射和透射。d = 0 时 T = 1、R = 0，恰好退化为恒等传播。

圆锥入射：按层切换完整 2N 阶 Schur 传播

1. 约化本征值 λ = 0 与真实 q = 0 的区别

A = Kₓ² − ⟦ε⟧，　B = Kₓ⟦ε⟧⁻¹Kₓ − I，　C = ⟦1/ε⟧⁻¹
A W₁ = W₁Λ₁，　BC W₂ = W₂Λ₂，　q² = λ + kᵧ²

原算法做两次 N 阶本征分解，再构造 2N 个完整电磁模式。构造式中第一组有 λ₁q₁，第二组有 W₂λ₂ 等因子。kᵧ ≠ 0 且 λ 接近零时，这些分量消失，两组列可能趋于相关；此时 q 可以仍等于 |kᵧ|。均匀介质在这种位置可以拥有完整半单本征空间，因此“构造式退化”与“完整 Maxwell 算符亏损”必须区分。

步骤代码实际行为
逐层检查kᵧ ≠ 0 且 min(|λ₁|,|λ₂|) < 10⁻² |kᵧ|1.5 时触发。
触发性质这是约化模式构造的近退化选择阈值；不把本征值截断为零，也不作为通用非厄米条件数判据。
完整算符在同一 Fourier 材料规则与场坐标中组装 P、Q，形成 H = PQ（2N × 2N）。

其他层继续原模式算法；默认均匀层快速路径使用解析模式。

2. 完整算符及其与一阶 Maxwell 系统的关系

在直角切向坐标下，令 E = ⟦ε⟧，原始 P、Q 为下式；实现随后用逐级次的电场、配对磁场旋转矩阵变换到 (s,t) 坐标。

P = [[kᵧKₓE⁻¹, I−KₓE⁻¹Kₓ],
　　 [kᵧ²E⁻¹−I, −kᵧE⁻¹Kₓ]]
Q = [[kᵧKₓ, E−Kₓ²],
　　 [kᵧ²I−C, −kᵧKₓ]]

旋转后的切向电场 F、配对磁场 U 满足 F′ = PU、U′ = QF，因此 F″ = PQF。设 HZ = ZT，G² = T，令：

W = Z，　VG = QZ　⇒　V = QZG⁻¹
PV = ZG，　QW = VG

于是下行分量 F = W exp(−ξG)a、U = −V exp(−ξG)a，和上行分量 F = W exp[−(h−ξ)G]b、U = V exp[−(h−ξ)G]b，均逐项满足一阶 Maxwell 方程。这给出了 Schur 传播与原物理系统的直接等价关系。代码通过右上三角求解 VG = QZ 得到 V，避免显式求逆。

3. 上三角平方根与 Jordan 项

Gii = outgoing_sqrt(Tii)
Gij = [Tij − Σi<k<jGikGkj] / (Gii + Gjj)

平方根按原求解器分支选择，使传播模保持相位约定、衰减模向外衰减。C++ 与 Python 均验证 ‖G²−T‖₁ ≤ 10⁻¹⁰ max(‖T‖₁,tiny)。精确零对角根、零除数或非有限中间量会触发数值失败。

若 T = q₀²I + J，J² = 0、q₀ ≠ 0，则：

G = q₀I + J/(2q₀)，
exp(−hG) = exp(−hq₀)[I − hJ/(2q₀)]

hJ 项就是广义模式的传播。删除上三角项，会得到错误的场和错误的层散射块。测试用 T = [[4,3],[0,4]] 核对 G₁₂ = 0.75 及矩阵指数的非对角项。

4. 与散射递推的接合

非零 G 的层传播块为 Tdd = Tuu = X，Rdu = Rud = 0。界面继续由 W、V 匹配切向场，随后使用既有 S 矩阵递推。每个方向的振幅锚定在它进入该层的表面，传播只经过非负距离，厚吸收层也沿这一约定处理。

更换基 W → WD、V → VD 时必须同步令 G → D⁻¹GD、a → D⁻¹a。原算法的逐列独立归一化只适用于对角传播；Schur 分支保留 Z 的酉基，不再独立缩放 W、V 的列。

5. 数值实现与可观察结果

C++ 的矩阵指数使用缩放 Taylor 展开及平方恢复，每次平方后用标量指数刷新对角线；这避免 diag(−10²⁰,−1) 中较慢衰减的分量在大量平方中被误算。空矩阵、10±200 平方根尺度、Jordan 耦合和溢出失败均有专门测试。

n_schur 记录实际切换层数，每层额外一次 QR 计入 n_eig。min_abs_lambda 和 degenerate_mode_warning 保留近退化诊断含义。自定义本征后端继续负责原两次 N 阶分解，Schur 回退使用内置 QR。这里“回退”由层内判据提前选择，不依赖整次求解产生 NaN 后重新猜测原因。

Python 近场：与层散射保持相同的解

1. 一个共享传播入口

新增 gui/mode_propagation.py。平面 rcwa1d.py 与圆锥入射的 modes_conical.py、rcwa_conical.py、fields_conical.py 共同使用它。ModeSet.schur_generator 保存 G，普通层保存 q。求解层散射块、恢复层内振幅、单点场和场图都读取同一模式表示。

2. 计算场图时保留耦合，同时控制内存

3. 同时修复未激发倏逝入射分量的溢出

原实现先为所有入射阶计算指数，在离结构较远的位置，未激发的倏逝阶也可能得到 Inf，随后 0×Inf 污染整个场。现在仅对非零入射振幅计算入射指数。平面和圆锥的单点场、场图均已修改；z = −100 μm 的回归测试在浮点溢出与 invalid 均设为抛错时通过。

独立一阶参照的构造

d/dξ [F;U] = [[0,P],[Q,0]] [F;U]

测试内部采用辅助状态 [F;−U]，所以实际指数生成矩阵写作 [[0,−P],[−Q,0]]，返回物理场时恢复 U 的符号。对这个等价的 4N 阶系统计算一个小厚度的矩阵指数，将传输关系换成 S 矩阵，再通过倍增组合到目标厚度。场点上下各自组装散射系统，从该点匹配得到 F、U。这一路径与生产实现的 2N 阶 Schur 平方根有不同的计算流程，能检出符号、坐标旋转、G 耦合、层厚锚定和界面接合错误。

另外的混合层数值复核中，与一阶参照的最大 Jones 差为约 1.21×10⁻¹¹；M = 16 的复核约为 5.88×10⁻¹²。自动测试的源文件见页面末尾；COMSOL 对拍脚本没有随发布。

实现中的失败与诊断边界

检测到 QR 不收敛、奇异线性系统、无效矩阵函数或非有限数时，C++ 按原接口返回 NaN 结果，Python 抛出相应数值异常。圆锥 Schur 平方根的对角根若精确为零，仍触发此失败路径；它使用 G⁻¹ 的场配对关系，因此与平面零根辅助基是两种不同分支。当前外部精确掠射的部分界面路径也仍含零分母；对应条件在头文件和零厚度/外部截止回归中明确保留。
