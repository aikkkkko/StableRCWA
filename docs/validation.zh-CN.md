# 验证

StableRCWA 的验证分两部分：

- **仓库里的自动测试：** C++ 测试程序（CTest）和图形界面的 Python 测试，克隆之后就能重跑。
- **与 COMSOL 有限元的独立对照：** 一维圆锥入射、二维交叉光栅、传播常数严格为零的截止情形，各有一份对照报告。
  对照所用的脚本和原始数据**没有随仓库发布**，下面只摘录报告的结论与数字，每张表下注明出自哪份报告的哪一节。
  两份讲解页给出图文版本：[圆锥入射-COMSOL对照](https://aikkkkko.github.io/StableRCWA/pages/圆锥入射-COMSOL对照.html)、[截止零根-Schur传播与COMSOL对拍](https://aikkkkko.github.io/StableRCWA/pages/截止零根-Schur传播与COMSOL对拍.html)。

## 一、自动测试

### 1.1 怎么跑

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j
cd build && ctest -C Release
```

共 25 项：21 个 C++ 测试程序，另有 4 项检查 JSON 模式开关的条目。

- **Windows：** `examples\run_tests_win.bat` 一条命令用 MinGW g++ 和 MSVC 两个编译器完成构建和测试，汇总写在 `build\tests_win\summary.txt`。
  编译器的位置必须先用环境变量指定：`MINGW_BIN` 是 `g++.exe` 所在的目录，`VCVARS` 是 `vcvars64.bat` 的完整路径。用法写在脚本开头。
- **持续集成：** `.github/workflows/ci.yml` 在 Ubuntu、macOS、Windows（MSVC）上做 CMake 构建并运行 `ctest`。
- **图形界面的 Python 测试：** 在 `gui/` 目录里运行 `python -m unittest discover -s validation -p "test_*.py"`。

### 1.3 参照从哪里来

- **圆锥入射有两个互相独立的测试程序。** `test_rcwa1d_conical` 与 Python 参照求解器算出的复 Jones 矩阵对拍；
  `test_rcwa1d_conical_physics` 是另外独立写的，参照只有三类：闭式解（膜系的特征矩阵法，先与 Fresnel、Airy 公式互相核对）；
  严格成立的关系（通量幺正性、互易性、镜像与平移、周期重复等价、正入射时基的旋转、由解析性给出的幂律）；
  已有的 TE/TM 求解器 `rcwa::solve`（φ = 0、180° 与正入射）。
- **二维的验收标准是冻结的 Python 参照**（`gui/validation/field_reference_2d/`，数值权威是 `gui/2drcwa/rcwa2d.py`）。
  `test_rcwa2d_reference` 里 21 个成功算例的远场与参照相差不超过 3.1e-13；`test_rcwa2d_fields` 的近场谐波列最大相差 3.6e-13，切面复场 1.1e-12
  （Apple clang，arm64）。换成 LR 时，这些算例要么与参照一致，要么报告数值失败，没有悄悄出错的。
- **一维近场**对 `gui/validation/field_reference/` 下 12 个冻结的六复场与相位参照，约定见同目录的 `CONTRACT.md`。

**其余结论：**

- **截断与网格：** 光栅算例对 M = 60 的差有相当一部分是 RCWA 的截断误差（M = 60 与 M = 200 之间相差 0.4e-6 到 2.7e-6）；
  换成 M = 200 作参照，差是 0.3e-6 到 2.6e-6，并随网格加密继续变小。正式网格与再密一档之间，所有算例的最大变化不超过 1.2e-6。
  没有看到不随网格、不随截断阶数消失的系统偏差。（报告 A 第 0 节、第 4 节）
- **截断扫描：** 光栅 A 上 M = 20、40、60、100、150、250、400 相邻两档之间的最大变化依次是 1.3e-5、1.9e-6、1.2e-6、4.0e-7、2.1e-7、7.0e-8。（报告 A 第 1.2 节）
- **吸收：** 吸收齿算例 COMSOL 的 1 − ΣR − ΣT 与 RCWA（M = 60）相差 +3.5e-6（s 入射）、+1.8e-6（p 入射）；
  COMSOL 的端口法与损耗体积分两个吸收值相同到 6 位。（报告 A 第 5 节表 D）
- **取向：** 对称的光栅 A 分辨不出结构的左右取向，所以加了非对称光栅：取向配对时差 1.6e-6，故意配错时差 9.0e-3。（报告 A 第 5 节表 F）
- **C++ 与 Python：** 同一批算例的 Jones 矩阵元最大相差 7e-13（M = 60）、7e-12（M = 200）。（报告 A 第 0 节）
- **残差的来源：** RCWA 的截断（M = 60 时约 1e-6 到 3e-6，光栅 A 上大致按 1/M² 下降）；有限元在齿角处的离散误差（正式网格下约 1e-6）；
  倏逝级到端口的残留（设计值 1e-8，端口移远 0.6 µm 后结果变化 5e-9）。（报告 A 第 7 节）

**两边约定的对应关系**（在 COMSOL 里复现时容易错的地方，报告 A 第 2 节）：

- 时间因子：RCWA 用 exp(−iωt)，COMSOL 用 exp(+jωt)，复振幅之间差一个复共轭。
- 坐标：COMSOL 的 x 是 RCWA 的 −x（再加一个平移），所以 **COMSOL 里的结构要取 RCWA 结构的 x 镜像**。
- 入射角：COMSOL 二维周期端口的入射角参数不是极角 θ，要设成 atan(tanθ·cosφ)；离面波数取 k0·nI·sinθ·sinφ。
  直接设成 θ 时模型照样能解、能量照样守恒，但算的是另一个入射方向。
- 级次：Periodic Structure 节点自动生成的端口两侧都是 m_COMSOL = −m_RCWA；稳妥的做法是按端口报告的面内波矢配对，不靠级次号。
- 入射偏振：S 激励的入射场是 +ŝ，P 激励是 −p̂。

**没有覆盖的**（报告 A 第 9 节）：只有一个波长（1.053 µm）和一个极角（42°）；方位角只到 80°；没有靠近 Rayleigh 截止的点（最近的离截止 0.051）；
传播级最多 6 个；只有矩形齿、分段常数的折射率，没有斜壁、圆角、金属；基底始终无吸收；只用了 COMSOL 6.4 这一个版本。
